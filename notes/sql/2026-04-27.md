## 오늘 푼 문제

### [프로그래머스 - 자동차 대여 기록에서 장기/단기 대여 구분하기](https://school.programmers.co.kr/learn/courses/30/lessons/151138)
- 유형: CASE WHEN + 날짜 계산
- 핵심
  - DATEDIFF(END_DATE, START_DATE) + 1 로 기간 계산 
  - 30일 이상 → 장기 대여 
- 실수
  - DATEDIFF 결과에 +1을 하지 않아 기간 계산 오류 
- 배운 점
  - 날짜 계산은 “포함 여부(+1)” 중요 
  - DATEDIFF는 단순 차이, 실제 기간과 다를 수 있음

[풀이]
```sql
SELECT
    HISTORY_ID,
    CAR_ID,
    START_DATE,
    END_DATE,
    CASE
        WHEN DATEDIFF(END_DATE, START_DATE) + 1 >= 30 THEN '장기 대여'
        ELSE '단기 대여'
    END AS RENT_TYPE
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE START_DATE BETWEEN '2022-09-01' AND '2022-09-30'
ORDER BY HISTORY_ID DESC;
```

### [프로그래머스 - 조건에 맞는 회원수 구하기](https://school.programmers.co.kr/learn/courses/30/lessons/131535)
- 유형: 조건 필터링 + COUNT
- 핵심
  - WHERE로 조건 필터링 후 COUNT 
  - 가입일 + 나이 조건 조합
- 실수: 없음
- 배운점: NULL은 BETWEEN 비교 조건에서 자동 제외됨

[풀이]
```sql
SELECT
    COUNT(USER_ID) AS USERS
FROM USER_INFO
WHERE JOINED BETWEEN '2021-01-01' AND '2021-12-31'
    AND AGE IS NOT NULL
    AND AGE BETWEEN 20 AND 29;
```
