## 오늘 푼 문제

### [PRG 42626 - 더 맵게](https://school.programmers.co.kr/learn/courses/30/lessons/42626)
- 유형: 우선순위 큐 (Heap)
- 핵심
  - 가장 작은 값 2개를 반복적으로 꺼내 섞음 
  - 섞은 값 = first + (second * 2)
  - 최소값이 K 이상이 될 때까지 반복
- 실수: 없음
- 배운 점 
  - “최소값을 계속 꺼내야 하는 구조 → PQ” 
  - 정렬은 1회성, PQ는 지속적 정렬

### [PRG 42747 - H-Index](https://school.programmers.co.kr/learn/courses/30/lessons/42747)
- 유형: 정렬 (Greedy)
- 핵심 
  - h-index = h번 이상 인용된 논문이 h편 이상 있는 최대 h 
  - 정렬 후 citations[i] ≥ (n - i) 조건으로 판단
  - 조건을 처음 만족하는 (n - i)가 정답 
- 실수 
  - index 기준으로 h를 계산하려고 해서 개수 기준이 틀림 
  - 내림차순/오름차순 기준 혼동 
- 배운 점 
  - 이 문제는 값이 아니라 “개수 기준” 문제 
  - i는 위치, (n - i)는 논문 개수라는 점이 핵심

## 🧠 오늘 배운 패턴
- Heap (PriorityQueue)
  - 최소/최대 값을 반복적으로 꺼내야 할 때 사용
- 정렬 기반 Greedy
  - 정렬 후 조건을 만족하는 범위를 찾는 방식

## ⚠️ 오늘 인사이트
- Heap vs 정렬 차이
  - 정렬 → 한 번 정렬
  - Heap → 계속 정렬 상태 유지
- H-Index 핵심 
  - “값 비교 문제가 아니라 개수 비교 문제”
